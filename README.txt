For programs 2.7 to 2.10:
1. Start Apache and MySQL from XAMPP.
2. Create a database named "test" in phpMyAdmin.
3. Put all PHP files inside htdocs.
4. Open the required file using:
   http://localhost/filename.php

If your MySQL username/password/database are different, edit:
$host, $user, $password, $database
at the top of programs 2.7 to 2.10.

No table is required for these four programs because they use MySQL built-in functions directly.
